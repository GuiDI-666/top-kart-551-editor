# Top-Kart 551 明文快照编辑器（协作版）

> **开源版说明**
>
> 本工具是纯 Python 实现，不依赖 `Top-Kart.dll`，可直接分发给协作调参的人使用。
> 开源仓库不包含任何 `.yml` 快照样本，快照需由主编辑器导出后生成。

`Top-Kart-551-Snapshot-Editor.exe` 是给参与调参的其他用户使用的独立工具，不需要 `Top-Kart.dll`、`551_object_init.bin`、服务端或 Python 环境。

## 使用方法

1. 把 EXE 发给参与编辑的用户，并提供需要修改的 SchemaVersion 1 `.yml` 快照。
2. 点击“打开快照目录”或“打开单个快照”。
3. 在形态页中双击数值修改；多形态快照提供并排对比页。
4. 点击“另存贡献稿”。工具默认写入 EXE 旁的 `快照编辑输出`，不会覆盖收到的原快照。
5. 将生成的 `.yml` 和同名 `.changes.txt` 修改清单一并发回。
6. 管理者使用主编辑器的“从快照生成密文”功能，配合同名 `CarrierFile` 原密文生成并执行 DLL 回读校验。

## 安全限制

- 仅接受 `SchemaVersion: 1` 快照以及整数/整数数组。
- `HasSkateParam`、`WeightNum`、`AntiCollisionNum` 等结构标记和数量字段只读。
- 数组长度不能在界面中增删，保存时会检查配重、防撞和对战技能数组长度。
- 协作版只编辑明文，不包含加密算法，也不能生成 551 密文。
- `SourceFile` 和 `CarrierFile` 元数据保持不变，避免贡献稿套用到错误载体。
